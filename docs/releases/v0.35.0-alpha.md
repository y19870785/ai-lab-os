# v0.35.0 Alpha 发布说明——Local Daily Operating Loop

## 1. 发布身份

- 版本：`0.35.0`
- 名称：`v0.35.0 Alpha — Local Daily Operating Loop`
- 类型：GitHub Pre-release 候选；不发布 wheel 或 sdist 附件
- 当前状态：`RELEASE_CANDIDATE_VALIDATED / DRAFT_PR_OPEN / PENDING_INDEPENDENT_REVIEW / NOT_PUBLISHED`
- 授权边界：`v0.35.0` Tag 与 GitHub Release 均为 `NOT_AUTHORIZED / NOT_CREATED`

## 2. 发布亮点

本版本汇总 SP-016～SP-020 已完成并通过正式验收的本地日常工作闭环：Waiting-For、
Work Log、Daily Review、Local Daily Profile、确定性 Action Hints、Review-to-Action，
以及受控 shutdown、restart 和静止备份/恢复。REL-035 只做发布收口，不新增产品行为。

## 3. 已验证能力

- Canonical Waiting-For Domain 与 Inbox confirmation（ACC-016、ACC-017）。
- Canonical Work Log query boundary（ACC-018）。
- `today` / `yesterday` Daily Review read model（ACC-019）。
- Windows Local Daily Profile、正式 Daily Review CLI、Action Hints 与 Review-to-Action（ACC-020）。
- Scheduler 持续运行、优雅和重复 shutdown、restart recovery、静止备份与隔离恢复（ACC-020）。

## 4. 支持入口

- CLI：`python -m cli profile --require-local-daily`、`python -m cli daily-review --date today`、
  `python -m cli daily-review --date yesterday --json`、Agenda、Inbox 与 Waiting-For 命令。
- API：`/health/live`、`/health/ready`、`/daily-review`、`/daily-review/action-hints`、
  `/agenda`、Inbox 与 Review-to-Action 路由。
- CEO Assistant：今日/昨日简报与既有 canonical service 边界。

## 5. 从 v0.34.0 升级

1. 停止 v0.34.0 进程并确认所有数据库连接已释放。
2. 完整备份 checkout 外的整个 data directory；不得复制运行中的 SQLite 数据目录。
3. 切换或安装 v0.35.0 release candidate。
4. 从 `config/local-daily.env.example` 对照现有配置，继续使用稳定绝对
   `AI_LAB_DATA_DIR` / `AI_LAB_SQLITE_DIR`，并核对 timezone、feature flags、
   API token 与完整 WorkspaceKey。
5. 先执行 `python -m cli profile --require-local-daily`，再启动服务并完成 health、auth、
   Daily Review、Agenda、Inbox/Waiting-For、Action Hints 与 Review-to-Action smoke。
6. 若验证失败，停止候选版本并从完整备份恢复；不要修改原数据副本继续试验。

## 6. 数据兼容性

数据兼容结论：No destructive database migration is required.

既有表结论：No existing v0.34.0 table rewrite is required.

旧数据处理：No legacy data import is required. No dual-write migration is required.

既有 UserTask、Reminder、Inbox 与 Work Log 保持原样。若 `followups.db` 不存在，
`waiting_for_items`、`waiting_for_events` 及相关索引只通过 `CREATE TABLE IF NOT EXISTS`
和 `CREATE INDEX IF NOT EXISTS` 增量初始化。升级验证必须在 v0.34.0 数据的隔离副本上进行。

## 7. 安全边界

Local Daily 仅绑定 localhost，并要求非示例 Bearer Token 与显式 CORS allowlist/deny-all。
它仍没有 OAuth、JWT、用户身份、RBAC、强多租户隔离或内建 TLS；不得描述为 production-ready。

## 8. 已知限制与未包含范围

本版本不包含 External Notification、Recurring Reminder、Web UI、完整 Knowledge 主链路、
自动 Tool Calling、完整 MCP/Agent Runtime 产品闭环、Docker 正式发布验证、企业级部署、
高可用或长期压力基线。Daily Review 只支持 `today` / `yesterday`，Action Hints 是确定性子集。

## 9. Release Candidate 验证要求

候选版本必须通过 Governance、Version、non-real 与 full pytest，修改 Python 文件 Ruff，
Local Daily Profile positive/negative validation，真实 service/CLI/API smoke，v0.34.0 隔离数据
兼容验证，wheel/sdist build 与 metadata 检查，以及全新环境安装和受支持 CLI 入口验证。
这不是 ACC-020 A～V 的重新执行。
